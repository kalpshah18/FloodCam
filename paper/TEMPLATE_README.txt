# ES 678 Course Project LaTeX Starter

This starter is for the ES 678 course project, not a NeurIPS submission. It uses the official NeurIPS 2026 two-column LaTeX style as a familiar machine-learning conference layout and adapts the title footer for the course.

## Files

- `es678_project_template.tex`: replace the marked prompts with your paper.
- `neurips_2026.sty`: unmodified style file from the official NeurIPS 2026 author kit.

## Compile

Upload both files to Overleaf and set `es678_project_template.tex` as the main file, or run:

```sh
pdflatex es678_project_template.tex
pdflatex es678_project_template.tex
```

Use the layout as supplied. Do not change margins, font sizes, or column layout. The ES 678 paper must be no more than four pages total, including references. The course limit is different from the page limit for an actual NeurIPS submission.

The NeurIPS 2026 author kit is available from the [official conference page](https://neurips.cc/Conferences/2026/CallForPapers). The included style file is provided for course formatting only.
