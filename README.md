# FloodCam

Estimating shallow flood depth (and whether it exceeds 3 cm) from fixed-camera video.
ES 678 course project, Kalp Shah (24110152).

## What is here

| | |
|---|---|
| **Real-footage study** | Real USGS gauge-camera frames labelled with the official gauge height: dataset builder, plate registration, learned reader, leave-one-month-out CV, locked test, resolution sweep, failure audit. All numbers: `results/real/SUMMARY.md` (generated by `scripts/real_report.py`). Data sources and licences: `docs/DATA_SOURCES.md`, `data/usgs/README.md` |
| **Dashboard** | `streamlit run app/dashboard.py`: upload a video and watch levels live; replay real USGS footage next to the gauge; replay recorded runs |
| **Synthetic generator** | `src/floodcam/synth/`: unit tests and the dashboard demo only; never used for reported results |
| **Trained model** | `models/in_overland/reader.joblib`; use via `floodcam.real.infer.PlateModel`; retrain with `python scripts/train_reader.py` |
| **Continuing the project** | `docs/FUTURE_GUIDE.md` (how it works, how to add data, rules, open items) |
| **Decisions and log** | `docs/DECISIONS.md`, `docs/EXPERIMENT_LOG.md`, `AI_USE.md` |

## Reproduce the real-footage results

```bash
pip install -e . --no-deps && pip install opencv-python-headless scikit-learn pandas matplotlib streamlit altair streamlit-image-coordinates pyyaml pillow
python scripts/build_usgs_dataset.py          # ~4k frames from the public USGS S3 bucket (~1 GB, gitignored)
python scripts/make_usgs_splits.py            # month-block splits (committed: data/splits/usgs_in_overland.json)
python scripts/build_refs.py                  # extra registration references (dev blocks only)
python scripts/extract_strips.py --site in_overland --factor 1
for f in 2 4 8 16 32 64; do python scripts/extract_strips.py --site in_overland --factor $f; done
python scripts/real_cv.py                     # leave-one-block-out CV on dev blocks
python scripts/real_resolution.py             # error / 3 cm detection vs cm per pixel
python scripts/real_final_test.py             # locked blocks; refuses a second run without --force
python scripts/real_report.py                 # figures, tables, SUMMARY.md, failure audit
python scripts/make_real_demo.py              # small bundle for the dashboard
```

## Claim limits

One camera per site; the effective sample size is the number of month blocks, not frames. Labels are
a gauge beside the plate, not tape measures. Depth below the plate bottom (about 4 cm) cannot be read.
The Flood/Recovering state machine is a demonstration, not an evaluated claim. The upload mode has been
validated on synthetic video only.
