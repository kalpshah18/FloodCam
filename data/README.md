# Data directory

Only small, public files are committed. Everything else is downloaded or generated by scripts and is
gitignored.

## Committed

| Path | Content |
|---|---|
| `usgs/README.md` | Source, licence and provenance of the USGS frames and gauge labels |
| `usgs/truth/*.csv` | Gauge labels (`file,time,gage_ft`) for every frame used; USGS NWIS, public domain |
| `usgs/demo/` | 68-frame sample of one held-out event, used by the dashboard and the tests |
| `usgs/cameras.csv`, `usgs/camera_survey.csv` | USGS camera list and which staff-gauge cameras report gauge height |
| `splits/usgs_*.json` | Month-block splits for each camera, including the locked test blocks (file IDs only) |
| `splits/synthetic_splits.json` | Splits for the synthetic test data (tests only) |

The split files are authoritative. Do not regenerate them: the locked test blocks were fixed before
any model was trained.

## Downloaded or generated (gitignored)

| Path | Created by |
|---|---|
| `usgs/frames/`, `usgs/manifest.jsonl` | `scripts/build_usgs_dataset.py` (frames from the public USGS S3 bucket, no credentials) |
| `usgs/strips/` | `scripts/extract_strips.py` (registered, rectified plate strips) |
| `synthetic/` | `make synth-demo` (synthetic frames for tests and demos; never used in results) |
| `public/`, `raw/` | Optional SegFormer track only; nothing was downloaded for the reported results |

See the root `README.md` (Data access) for the exact commands. A protocol for recording your own
tape-measured data is in `docs/RECORDING_PROTOCOL.md`.
